# MistakePrint

把**含 LaTeX 的错题题干**（纯文本）渲染成**宽度精确匹配热敏打印机点阵**的 1-bit 位图，再由用户手动分享给「作业帮喵喵机」官方 App 打印。

- 面向场景：作业帮等 App 的错题打印，题干里混有中文、数学公式与教材符号。
- 目标机型：**喵喵机 P1**（203 dpi，有效打印宽度 384 点；默认档案已按实机校准回填）。
- 平台：Android 手机端，Flutter + Material Design 3。

## 非目标（明确不做，避免范围漂移）

- **不做蓝牙 / BLE 通信**，不生成 ESC/POS、CPCL、TSPL 等打印机指令，不直接驱动打印机。
- 不做设备配对、不接入喵喵机 SDK、不自动化其官方 App。
- **不处理图片输入**（无图题、无扫描件）。
- 不做 OCR，不做题库管理，不做错题本业务。
- 化学式（mhchem `\ce{}`）为后续增量，不阻塞首期。

终点是「输出图片并交给用户分享」，打印由官方 App 完成。

## 用法

1. 打开 App，首页就是一个大输入框。把 AI 生成的错题解答**整段粘**进去即可：
   **裸 LaTeX**（没有 `$` 包裹的 `\frac`、`\log` 之类）会自动识别成公式，不需要手动补定界符；
   输入时输入框下方会实时显示「识别到 N 处公式」。
2. 顶部切换输出模式：**「只打印题干」**或**「题干 + 解答」**（默认后者，选择会被记住）。
3. 点「生成图片」，进入预览页。这一页会给出尺寸（点数）、黑点占比、排版轮数与耗时，
   以及预处理与降级提示（识别情况、未闭合的公式等）。
4. 点「分享到喵喵机 App」，在系统分享面板里选喵喵机 App 打印。

图片同时会落盘到应用缓存目录下的 `mistake_print/`，文件名形如
`mistake_20260927-123428-384x1234.png`，预览页会显示完整路径——分享面板没起来或没找到目标 App 时，
可以按这个路径手动取图，再用喵喵机 App 内的「导入图片」打印。

两点注意：

- 出图宽度**严格等于**机型档案的点阵宽度（默认 384 点，1:1 不做缩放）。
  导入喵喵机 App 时请**关掉自动裁剪与图像增强**，否则细线会被糊掉、内容可能被裁。
- 单次输入上限 **12000 字**，出图高度上限 **12000 点**，超了会提示拆题后再打。

## 校准向导

入口：**设置 → 打印校准**。用纸：主校准条 **1 张（约 200mm）**，一次打印回答全部问题，
不需要「打了再打」。

1. 点「生成校准条并分享」，在预览页把校准条分享给喵喵机 App 打印。
2. 对照打印结果回答 7 项——每一项都能**跳过**，跳过就用默认值：

   | # | 项目 | 怎么答 |
   |---|---|---|
   | ① | 有效宽度 | 校准条右边那条线里，看得见的最外面一个数字是几 |
   | ② | 宽度异常 | 右边留了白边说明打印 App 把图缩小了（会自动切 pHYs） |
   | ③ | 最小可读字号 | 最小的、仍然看得清的是哪一档（只记下限，不改正文字号） |
   | ④ | 正文字号 | 正文用哪一档读着最舒服（不会小于上面选的最小可读字号） |
   | ⑤ | 细线保真 | 哪一列的分数线是完整的一条 |
   | ⑥ | 阈值档位 | 哪一档最清楚 |
   | ⑦ | 灰阶 | 能分辨出几档（**只作诊断**，不改任何参数） |

3. 点「用新参数出一张样例」确认效果，满意后点「保存到档案」。设置页里的
   「重置为出厂默认值」可一键还原。

校准请用**同一卷纸、同一电量、同一应用版本**，结果才有可比性。全部跳过时档案保持原样，
用默认值本来就能直接出图。

## 公式支持边界

计划把下面这些**明确推到 1.0 之后**，当前版本不保证表现，强依赖它们的题目请先自行试印：

- `\text{中文}` 里的中文会以公式字体渲染，不走正文通道。
- 教材符号（`▱ ≌ ∽ ⌢ ①②③` 等）未做完整的字体覆盖断言，可能出现**豆腐块（方框）**。
- 化学式（`\ce{}`）暂不支持。
- `aligned` / `cases` / `\dfrac` 等环境未专门适配，只会走公式库自带的兜底行为。

**超宽公式**不是边界：它会走 `texBreak` 断行，断不动的片段再整体缩小并给出告警，不会静默裁切。

## 故障排查

| 现象 | 处理 |
|---|---|
| 出现方框（豆腐块） | 该字符没被字体覆盖，见上节「公式支持边界」 |
| 分数线、细竖线断成虚线或消失 | 设置 → 细线增强 调「标准」（默认）或「激进」；仍不行再走校准向导第 ⑤⑥ 项重选 |
| 打出来整体偏大或偏小 | 设置 → 输出 → 切换「写入打印机分辨率元数据」 |
| 右边被裁掉，或右边留白边 | 走校准向导第 ①② 项（有效宽度 / 宽度异常） |
| 分享面板里没有喵喵机 App | 先在喵喵机 App 内确认支持从系统分享导入；预览页会显示图片路径，可手动取图后用 App 内的「导入图片」打印 |
| 提示「输入 N 字，超过单次上限 12000 字」或「内容高度 N 点超过上限 12000 点」 | 拆成多道题分别出图 |
| 某段没排成公式、被当纯文本了 | 预览页会列出降级提示（如「未闭合的公式定界符」）。补上配对的 `$`；若 `$` 被当成货币符号，改用 `\(...\)` 显式包裹 |
| 出图偏慢 | 内容越长，超采样倍率会自动降低，长图更慢属于预期；单题（约 400 字、20 个公式）离线实测远低于 3 秒 |

## 构建与检查

```powershell
$env:PATH = "C:\Users\admin\library\flutter\bin;$env:PATH"
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

release 签名从 `d:\code\keystore` 引用（`android/key.properties` 不入库且不含口令）；
构建后用 `apksigner verify --print-certs` 确认签名 DN 是 `CN=MistakePrint`，回落成
`CN=Android Debug` 说明取不到 release keystore。
